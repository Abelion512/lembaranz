# Support Policy

Thank you for using **Lembaranzz**! We want to ensure you have the best experience possible while maintaining your data sovereignty.

## How to Get Support

Please follow these steps to find answers or report issues:

### 1. Check the Documentation
Before opening an issue, please check our [official documentation](https://github.com/Abelion512/lembaranzz/tree/main/docs). Many common questions about setup, encryption, and CLI usage are covered there.

### 2. GitHub Discussions
For general questions, "How-to" inquiries, or sharing your setup, please use [GitHub Discussions](https://github.com/Abelion512/lembaranzz/discussions). This is the best place for community support and architectural conversations.

### 3. Report a Bug or Request a Feature
If you've found a technical issue or have a suggestion for improvement:
- Search existing [Issues](https://github.com/Abelion512/lembaranzz/issues) to see if it has already been reported.
- If not, open a new issue using the appropriate template.

## Security Issues
**Do NOT report security vulnerabilities via public GitHub issues.**
Please refer to our [Security Policy](SECURITY.md) for instructions on how to responsibly disclose vulnerabilities.

## Response Time
Lembaranzz is an open-source project maintained with heart ❤️. While we strive to respond to all inquiries promptly, please understand that response times may vary.
