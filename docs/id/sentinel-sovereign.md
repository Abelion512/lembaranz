# Sentinel Sovereign: Agen Otonom Berdaulat

**Sentinel Sovereign** adalah asisten otonom tingkat lanjut yang tertanam di dalam Lembaran untuk menjaga, memantau, dan memperbaiki infrastruktur IT Anda secara mandiri.

## 1. Filosofi Kedaulatan

Berbeda dengan asisten berbasis chat tradisional, Sentinel adalah sebuah **daemon** (proses latar belakang) yang bekerja berdasarkan target (goal-oriented). Ia memiliki "Otak" untuk merencanakan dan "Tangan" untuk beraksi.

## 2. Fitur Utama

### 🤖 Otak Modular (Pujangga)
Sentinel dapat menggunakan model AI pilihan Anda (Gemini untuk kecerdasan maksimal atau Lokal untuk privasi mutlak) untuk merencanakan langkah pengerjaan tugas.

### 🛡️ Filtrasi Rahasia (Secret Scrubber)
Keamanan adalah prioritas. Setiap data yang diproses oleh AI akan disaring terlebih dahulu. Password atau token Anda tidak akan pernah mencapai mesin AI.

### ⚡ Pemulihan Mandiri (Self-Healing)
Jika sebuah tugas gagal (misal: build error atau file hilang), Sentinel akan menangkap log kegagalan tersebut, menganalisisnya, dan mencoba memperbaikinya sendiri tanpa menunggu instruksi baru dari Anda.

## 3. Cara Penggunaan

Gunakan perintah berdaulat untuk memberikan tugas otonom:

```bash
lembaran berdaulat "periksa integritas file dan perbaiki jika ada yang rusak"
```

### Opsi Tambahan:
- `--ai [gemini|none]`: Pilih penyedia kecerdasan.
- `--saku|--pelataran`: Pilih konteks brankas (Personal atau Proyek).

## 4. Transparansi dan Audit

Anda memegang kendali penuh. Setiap aksi yang dilakukan Sentinel dicatat di dalam **Laporan Privasi**. Gunakan TUI Lembaran (menu `🛡️ Laporan Privasi`) untuk melihat jejak pikiran dan tindakan Sentinel.

---
**Peringatan**: Gunakan fitur otonom dengan bijak. Seluruh tanggung jawab atas eksekusi perintah diserahkan sepenuhnya kepada pengguna.
