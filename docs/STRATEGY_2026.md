# Lembaranzz Strategic Strategy 2026

## The Threat Landscape (Q2 2026)

1. **Context Harvesting:** Big tech "free" tools now harvest local file metadata to train proprietary agents.
2. **Subscription Exhaustion:** Simple utilities have been swallowed by expensive SaaS bundles.
3. **Agent Dependency:** Users no longer "use apps"; they "task agents." If your data is locked in a vault the agent can't see, you'll abandon the vault for convenience.

## Strategic Pillars

| **Strategic Pillar** | **Concept** | **Impact** |
| :--- | :--- | :--- |
| **The Agent Bridge** | A restricted local API (Unix socket) allowing AI Agents to query the vault *only* after a manual TUI "Yes/No" approval. | Lembaranzz becomes the **Memory for your Personal AI**, keeping secrets out of the LLM provider's cloud. |
| **Quantum Sovereignty** | Moving from AES-256 to Post-Quantum Cryptography (PQC) primitives for the "Portable Backup" format. | Marketing as the **"First Quantum-Ready Vault"** creates a moat against legacy competitors. |
| **Local-First Sync** | Using **P2P Local Discovery** (WebRTC/Local Network) to sync between Laptop, Phone, and Tablet without a central server. | Beats the "Cloud Subscription" trap while maintaining 100% data sovereignty. |
| **Peta Aksara (Graph)** | Completing the encrypted knowledge graph. | Visualizes connections between your secrets, codebases, and personal notes, making the vault a **Local Brain**. |

## Roadmap Phase 3 (Expansion)

- [ ] **Agent Bridge (Unix Socket):** Implement the restricted local API.
- [ ] **PQC Integration:** Research and implement ML-KEM (Kyber) or similar for backups.
- [ ] **P2P Sync:** Prototype WebRTC discovery for local devices.
- [ ] **Peta Aksara UI:** Build the visual graph view for notes and secrets.
