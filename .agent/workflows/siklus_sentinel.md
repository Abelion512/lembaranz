# ⚔️ Workflow: Aktivasi Sentinel Sovereign

Gunakan workflow ini untuk memulai misi otonom dengan aman:

1. **Persiapan**: Pastikan file `.env` sudah memiliki `GEMINI_API_KEY` jika ingin menggunakan mode cerdas.
2. **Inisialisasi**: Jalankan `lembaran pantau --pelataran` untuk memastikan integritas brankas proyek.
3. **Misi**: Jalankan `lembaran berdaulat "[GOAL]"` (Contoh: "audit semua folder src").
4. **Verifikasi**: Periksa menu `🛡️ Laporan Privasi` setelah 3 siklus pengerjaan untuk mengaudit hasilnya.
